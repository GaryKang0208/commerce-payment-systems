SPARTA SHOP 구독 결제창 테스트 ← 일반 결제 테스트
사용 순서
  1. Postman으로 로그인 API를 호출해 JWT 토큰을 발급받습니다.
  2. 아래 결제자 정보를 입력하고 카드 등록 (빌링키 발급)을 클릭합니다.
  3. PortOne 빌링키 발급창에서 카드 정보를 입력합니다.
    (토스페이먼츠 테스트 인증 번호: 000000)
  4. 발급 완료 후 화면에 표시되는 billingKey를 복사합니다.
  5. Postman으로 구독 생성 API에 billingKey(+ planId 등)를 포함해 요청합니다.
    ※ 이 단계에서 실제 구독이 생성·활성화됩니다.
